# Repo Guide

## Purpose

`brotli-dec-wasm` is a decompressor-only Brotli package for browsers and web
workers. The core decoder is Rust compiled to WASM with `wasm-bindgen`; the npm
package exposes a small ESM wrapper that initializes the WASM module once.

## Architecture Map

- `src/lib.rs` is the Rust WASM entry point. It exports one-shot decompression as
  `decompress` and wires Rust modules into the generated JS API.
- `src/stream.rs` owns streaming decompression. It wraps
  `brotli_decompressor::BrotliDecompressStream`, tracks `total_out`, and exposes
  `DecompressStream` for compatibility with `brotli-wasm`.
- `src/err.rs` exports positive WASM-safe decoder error codes that mirror the
  negative Rust decoder errors.
- `src/utils.rs` contains shared WASM setup, currently the panic hook.
- `index.ts` is the public package entry. It imports the generated
  `pkg/brotli_dec_wasm.js`, memoizes `_init()`, and exports the init promise.
- `pkg/` is generated by `wasm-pack build -t web` and is ignored by git. Do not
  hand-edit it. Change Rust or `index.ts`, then rebuild.
- `example/webpack/` checks direct WASM asset usage and webpack async WASM usage.
- `test/` contains browser tests and benches. Fixtures are generated by
  `test/gen_fixture.js`.

## Build Flow

1. Rust source in `src/` builds to WASM and generated JS under `pkg/` via
   `pnpm run build:wasm`.
2. `index.ts` builds to `index.js` and `index.d.ts` via `pnpm run build:ts`.
3. `pnpm run minify` minifies the generated WASM JS glue and the package entry.
4. The published package exports the default wrapper at `.` and raw WASM-pack
   files at `./web` and `./web/bg.wasm`.
5. `wasm-pack-version.txt` holds the `wasm-pack --version` output that CI
   installs. Edit it to move the pinned version, and publish with that same
   version so the released WASM matches what CI builds.

## Working Rules

- Manage deps with pnpm.
- Keep this package decompressor-only. Do not add compression paths unless the
  product goal changes.
- Keep the public API compatible with the README examples and the
  `brotli-wasm` compatibility names: `decompress`, `DecompressStream`, and
  `BrotliStreamResultCode`.
- Prefer small changes in Rust for decoder behavior and small changes in
  `index.ts` for package init or export behavior.
- Do not commit generated build output unless the repo policy changes. Current
  generated paths include `pkg/`, `index.js`, and `index.d.ts`.

## Verification

- For Rust-only changes, run `cargo fmt --check` and
  `cargo clippy --all-features -- --no-deps -Dwarnings`.
- For JS, WASM, or public API changes, run `pnpm run build` and `pnpm run test`.
- For formatting-only checks, run `pnpm run format:check`.
- For dependency security work, audit both lockfiles: root `pnpm-lock.yaml` and
  `example/webpack/pnpm-lock.yaml`.

## Updating This File

Update `AGENTS.md` in the same change when the repo architecture changes. Keep it
short and factual: add or change navigation notes, ownership of modules, build
flow, and verification steps. Do not record transient plans or release notes
here.
